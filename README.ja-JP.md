# WeeklyGameJam166-Roots
[英語版 (English)](./README.md)

![Cover image](./RawAssets/Screenshots/Screenshot1.png)

このゲームでは、木の根を誘導して土の中の栄養を集めることで、木を成長させていきます。<br/>
土の中を進むには「成長ポイント」が1つ必要になりますが、これは栄養を集めることで回復できます。<br/>
また、途中で障害物に遭遇することもありますが、それを避けて迂回するか、突き破って掘り進むかはあなた次第です。

[itch.io](https://itch.io/)において2020年9月4日〜2020年9月11日に開催された「Roots（根）」というテーマの「Weekly Game Jam 166 ゲームジャム」への提出作品として制作されました。

本ゲームは、[Unity](https://unity.com)ゲームエンジンとC#で作られています。

ゲームは[こちら](https://jayzonty.itch.io/branch-and-grow)からブラウザ上でプレイできます。
