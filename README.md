# WeeklyGameJam166-Roots
[Japanese (日本語版)](./README.ja-JP.md)

![Cover image](./RawAssets/Screenshots/Screenshot1.png)
 
In this game, you make your tree grow by guiding your tree's roots to gather nutrients in the soil.<br/>
Navigating through the soil requires 1 branching point, which can be recovered as you collect nutrients.<br/>
You will also encounter obstacles, and it's up to you whether you want to go around them or dig through them. 

This game was made as an entry for Weekly Game Jam 166 in [itch.io](https://itch.io/), which ran from September 4, 2020 - September 11, 2020, with the theme "Roots".

This game was made using the [Unity](https://unity.com) game engine and C#.

You can play the game in a browser [here](https://jayzonty.itch.io/branch-and-grow).
